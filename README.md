# Ilahi Computer Center – Common Service Center Portal
Main Bazar, Town Chhapraulli, Dist. Baghpat, UP – 250617 · Since 2020

## Codespaces me chalane ke liye
1. GitHub par repo banao aur ye poora folder push karo.
2. **Code → Codespaces → Create codespace**. Apne aap `npm install` + `npm start` chalega, port 3000 browser me khulega.
3. Manual: `npm install && npm start`

## Login
- Admin: ID `admin`, Password `admin123` (badalne ke liye `ADMIN_PASS=xyz npm start`)
- User: Sign Up se mobile number + password banao.

Data `data/db.json` me save hota hai.
